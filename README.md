# UI Daily Challenge

تطبيق ويب لتحدي تصميم واجهات المستخدم في نوفمبر 2026: اسحب تحديًا من 30 تحديًا، نفّذه، وسجّل إنجازك وتابع تقدمك. تُحفظ البيانات في LocalStorage داخل المتصفح، ولا يحتاج التطبيق إلى خادم.

## التشغيل

```bash
npm install
npm run dev
```

```bash
npm test
npm run build
npm run preview
```

## الاستخدام على الجوال

شغّل `npm run dev:phone`، ثم افتح عنوان Network الظاهر في الطرفية من جوال متصل بشبكة الـ Wi-Fi نفسها. يُحفظ تقدم كل جهاز في متصفحه، ولا تتزامن الأجهزة.

## خط ثمانية

يستخدم التطبيق خط Thmanyah Sans إذا كان مثبتًا على الجهاز، وإلا فيعرض Noto Kufi Arabic وReadex Pro المضمّنين. نزّل الخط من الموقع الرسمي [font.thmanyah.com](https://font.thmanyah.com) وثبّته، ثم أعد فتح المتصفح. لا تضف ملفات الخط إلى هذا المشروع: [الرخصة](https://font.thmanyah.com/licenses) تمنع رفعها أو استضافتها على أي موقع أو خادم.

## النشر

ناتج `npm run build` موجود في `dist/` وهو ملفات ثابتة تعمل على Vercel أو Netlify أو Cloudflare Pages أو GitHub Pages. المسارات نسبية (`base: './'`)، فيعمل التطبيق من جذر النطاق أو من مجلد فرعي.

## البنية

```
src/
  data/challenges.ts      قائمة التحديات الثلاثين
  lib/progress.ts         قواعد القرعة والإنجاز (دوال نقية مختبرة)
  lib/storage.ts          الحفظ والاستعادة والتحقق من البيانات
  hooks/useDrawSequence   تسلسل حركة القرعة
  hooks/useProgress       الحالة والمزامنة مع LocalStorage
  components/draw/        اللوحة ومربع التحديد وبطاقة التحدي
  components/progress/    الإحصائيات والمسطرة
  components/challenges/  سجل التحديات المسحوبة والمنجزة
  components/ui/          مكوّنات عامة قابلة لإعادة الاستخدام
```

## قواعد القرعة

- تختار القرعة فقط من التحديات التي لم تُسحب في الدورة الحالية ولم تُنجز.
- التحدي المسحوب غير المنجز لا يعود إلى القرعة، ويبقى متاحًا للفتح والإكمال من السجل.
- «أعد ضبط السحب» يعيد التحديات غير المنجزة إلى القرعة ويبقي الإنجازات.
- «امسح كل التقدم» يحذف كل البيانات بعد التأكيد.

## الهوية البصرية

الفكرة المحورية هي مربع التحديد في برامج التصميم: يقفز بين الخانات ثم يتمدد ليصبح بطاقة التحدي. الألوان والخطوط معرّفة في `src/index.css`.
